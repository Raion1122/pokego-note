何回で倒せる？（ダイマックス技の回数を逆算）

  • 前提：相手のHP 約75,000（Dittobase の推定値。公式の数字は未発表）、相手の防御の補正 0.85（Pokebase の初期値）。この計算で Lv40・100%のカイリキーをディアルガに当てると1発345になり、Dittobase の数字と一致。個体値は15/15/15として、CPからレベルを逆算。キノコ（2倍）・応援・相手の強化は入れていない
  • 1発のダメージと、ひとりで倒すのに要る回数（Lv1 → Lv3 にしたとき）
  • サーナイト（ようせいのかぜ → ダイフェアリー）：1発 198 → 379発 ／ Lv3：277 → 271発
  • サーナイト（今のねんりき → ダイサイコ）：1発 124 → 605発 → 通常技をようせいのかぜに替える
  • ジジーロン（ドラゴンブレス → ダイドラグーン）：Lv40・100%なら1発 239（Lv3：335）。CP・通常技を確認したら計算し直す
  • 参考：ニンフィア Lv40・100% は 212（Lv3：297）。ハピナス（はたく）は 87 → 攻撃には使わない
  • ダイマックス1回 ＝ 1人3発。4人なら1回で12発
  • 4人全員がサーナイト並み（約200）なら：1回で約2,400 → ダイマックス約32回。全員 Lv3（約280）なら約3,300 → 約23回
  • 近道：①サーナイトの通常技を替える ②ダイフェアリーを Lv2～3 に ③マックスキノコ（2倍）
  • 一度に何人で戦えるかで回数が大きく変わる → 当日にゲーム内で確認

並びと動き方

  • 並び：サーナイト（攻撃＋りゅうせいぐんの受け）／ジジーロン（攻撃）／ハピナス（回復）／シャワーズ（受け・手元に戻せたら）
  • ハピナス：4つの技すべてで受けやすい順の1位 → 回復と受けの両方を任せる
  • シャワーズ：だいもんじ・ハイドロポンプ・アクアテールをいまひとつで受けられて、HPも多い → パルキア戦の受け役に向く。預け中なら11/15までに手元へ。CP・スペシャル技を確認する
  • サーナイト：りゅうせいぐんはほぼ効かない（フェアリー）。みず技・だいもんじは等倍
  • ジジーロン：りゅうせいぐんが弱点（288） → 技名がりゅうせいぐんなら下げる
  • 出さない：ドサイドン（ハイドロポンプ415）・エースバーン（ハイドロポンプが弱点）・メタグロス（だいもんじが弱点）・ゲンガー
