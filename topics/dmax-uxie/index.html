ダイマックス ユクシー 攻略（10/24 土）

← 一覧
  • マックスバトルデイ 10/24(土) 14:00～17:00（3時間だけ）。ダイマックス ユクシー（エスパー）は初登場の★5。日本で出るのはユクシーだけ（エムリット・アグノムはほかの地域）。色違いあり
  • 弱点：むし・ゴースト・あく（2倍）。手持ちではゲンガー（ダイホロウ）とメタグロス（れんぞくぎり→ダイワーム）の2体が弱点を突ける
  • ねらい目の技：スピードスター（65）。いちばん危ないのは みらいよち（138）
  • 防御がとても高い（種族値270）ので1発のダメージは小さいが、攻撃は低い。2人でも勝てる（ポケらく）が、約5分で暴走するので4人がおすすめ

    ボスの攻撃のルール

    • ボスが撃つのはゲージ技の3つだけ：みらいよち・かみなり・スピードスター から選ばれる。捕まえたユクシーの通常技ねんりき・じんつうりきはボスは使わない
    • 技の組み合わせは挑戦ごとに決まる：1回のバトルで使う技は入るたびに抽選され、入り直すと変わることがある
    • ボスの攻撃には「単体攻撃」と「全体攻撃」の2種類がある
    • 単体攻撃（スペシャル技）：威力2倍（出典：みんポケ）。自分のポケモンの頭の上に3本線（黄色い光）が出て、約1秒後に当たる。左右にスワイプすると避けられる（ギリギリで避けるほどダメージが減る：すぐ避けると約5割減、線が点滅する直前で約7割減）
    • 全体攻撃：「○○の全体攻撃！」と予告の帯が出て、場に出ている全員に当たる。避けられない
    • 全体攻撃で削られる大きさは みらいよち ＞ かみなり ＞ スピードスター の順（1サイトのみ：みんポケの試算）
    • 戦い方：3本線（黄色い光）が出たら左右にスワイプで避ける。「○○の全体攻撃！」の予告が出たら、ダイウォールを張るか、その技に強い受け役に交代する（下の『技の組み合わせ別の受け役』参照）
    • 負けてもマックス粒子（MP）は減らない（ポケらく）→ 技の組み合わせが合わなくても、気にせず入り直してよい
    • 出典：みんポケ(9db) 26537・回避のしかた 20853／ゲームペディア 120565／ポケらく post163995／ポケモンWiki「マックスバトル」。「威力2倍」はみんポケの情報（1サイトのみ）

    サイトで違っていた点

    • 単体攻撃と全体攻撃で「使う技」が同じか別かは、サイトによって書き方が食い違っている（どちらが正しいかは未確認）
    • みんポケ（9db）のユクシーのページ：同じ技が単体でも全体でも来る
    • ポケモンWiki：単体攻撃と全体攻撃では使う技が別
    • どちらでも「来た技名を見て受け役を合わせる」動き方は変わらない。出典：みんポケ(9db) 26537・ポケモンWiki「マックスバトル」

    技の組み合わせ別の受け役

    • 1回のバトルは『全体攻撃1つ＋単体攻撃1つ』。来る技で前に出す受け役を変える。最初の技が出るまで組み合わせは分からないので、まずは弱点のないハピナスで受け、技名を見てから下のとおり入れ替える
    • 【かみなりが入る組み合わせ】
    • 受け候補はドサイドン（かみなり 39・ほぼ効かない／スピードスター 41・いまひとつ）とドリュウズ（かみなり 39・ほぼ効かない）。でんき技がほとんど通らない
    • 注意：2体ともダイウォールを持っていない（ドサイドン＝ダイアース Lv2 のみ／ドリュウズ＝ダイアース Lv1 のみ）→ ダイマックスしても盾は張れない。盾を張りたいときはメタグロス（ダイウォール Lv2）かハピナス（ダイウォール Lv1）
    • 【みらいよちが入る組み合わせ】
    • 受けはメタグロス（みらいよち 54・ほぼ効かない／スピードスター 41・いまひとつ）。はがね・エスパーで、いちばん危ないみらいよちをほぼ無効化。ダイウォール Lv2 も持つので盾も張れる＝みらいよちの日の主役
    • ゲンガーはみらいよちが弱点（221） → みらいよちが入っているときは前に出さない。攻撃したいときだけダイマックスで一瞬出す
    • 【かみなり・スピードスターの組み合わせ＝当たり】
    • どちらも弱点にならず、ドサイドン・ドリュウズ・メタグロスで軽減できる → 少人数のときは、この組み合わせになるまで入り直すのが定番（負けてもMPは減らない）。みらいよちが入らないので事故が少ない
    • 【ハピナス＝受けと回復のどちらにも使える】
    • ダイウォール Lv1・ダイリカバリー Lv2 の両方を持ち、どの技も等倍でHPがとても多い
    • 受けとして：みらいよち 138／スピードスター 65／かみなり 100 を等倍で受けつつ、ダイウォール Lv1 で全員を守れる。弱点がないのでどの組み合わせでも最初の盾に使える
    • 回復として：ダイリカバリーは Lv2（Lv1 より回復量が多い。下の「戦い方のコツ」参照）→ 受けをメタグロス（みらいよち）・ドサイドン（かみなり）に任せられるときは、ハピナスは回復に専念させるのが基本。盾役を出せないとき（ドサイドン・ドリュウズしか前にいないとき）だけ、ハピナスを盾に回す
    • 数字は全体攻撃1発の目安（威力×相性）。単体攻撃はこの約2倍（威力2倍＝みんポケ）。手持ち・技レベルは my_dmax.json（2026-10-24）より

    並びと動き方

    • メタグロス：みらいよちはほぼ効かない（54）、スピードスターも いまひとつ。かみなりだけ等倍 → 受けと攻撃を両方こなす主役
    • ゲンガー：1発282（ダイホロウ Lv3・CP2500）で手持ちいちばんだが、みらいよちが弱点（221）→ 攻撃のときだけ出して、受けには使わない
    • ハピナス：どの技も等倍で HP が多い → 回復役。2体目のハピナスを受けにする手もある（ゲームウィズのおすすめはハピナス2体＋ゲンガー）
    • ドサイドン：かみなりはほぼ効かない、スピードスターもいまひとつ（みらいよちは等倍）→ 技がかみなりのときの受けの控え
    • 出さない：シャワーズ・インテレオン（かみなりが弱点）、フシギバナ・カイリキー（みらいよちが弱点）

    戦い方のコツ

    • 出陣させる3体：ゲンガー・メタグロス・ハピナス（ゲンガー＝攻撃／メタグロス＝攻撃・みらいよちの盾／ハピナス＝最初の盾・回復）。マックスバトルに連れて行けるのは1人3体まで。下の入れ替えはこの3体の中で行う
    • 最初の受け役はハピナス：ボスの技（狙い撃ち・全体攻撃）は1回使われるまで分からない（ほかの人に当たっても技名は出る）→ 技名が分かるまではハピナスで受ける（どの技も弱点にならず、HP が多い）。分かったら下のとおり入れ替える
    • みらいよちなら → 盾をメタグロスに替える（ほぼ効かない）。攻撃はメタグロスでいく（ゲンガーは「みらいよち」が弱点なので、ダイマックス以外は下げておく）
    • スピードスターなら → 盾はそのままハピナス（等倍）。攻撃はゲンガー・メタグロスでいく
    • かみなりなら → 盾はそのままハピナス（等倍）。攻撃はゲンガー・メタグロスでいく
    • 野良では抜けずに受け役を入れ替える：ボスの技（狙い撃ち1つ＋全体攻撃1つ）は挑戦ごとに抽選されるが、途中で抜けると残りの3人が不利になる → 技名を見て、その技に強い手持ちに替える。入り直し（MP は勝ったときだけ減る）は知り合いと組んで、全員で決めたときだけ
    • タンクは通常技だけ連打：スペシャル技よりメーターが早くたまる。0.5秒の通常技（ハピナスのはたく・メタグロスのれんぞくぎり）が向く
    • エネルギーはスワイプで取る（タップではない）。アイコン1個でメーター +10%
    • ダイマックス中は「盾 → 回復 → 攻撃」の順で決める：まずダイウォール（3回まで重ねがけ）、HPが減っていればダイリカバリー、それ以外はダイ攻撃
    • ダイリカバリーは同じ4人グループの「場に出ている」4体だけ回復。控えのポケモンは回復しない
    • 回復量は使ったポケモンの最大HPが基準：Lv1 8%・Lv2 12%・Lv3 16% を4体に同じ量 → ハピナス（HP397）で Lv1 は 31、Lv2 は 47。Lv2 に上げるのが先
    • 勝負は約5分：開始 約4分30秒で「暴走寸前」と出て、約5分～5分30秒で暴走する（伝説★5はボスの攻撃が約3倍、★3は約9倍）。暴走後はすぐ全滅しやすい → 「暴走寸前」が出たら盾・回復はやめてダイ攻撃だけ。ダイマックスは出し惜しみしない（9db・Bulbapedia。決まった時間切れは無く、英語の Bulbapedia だけ約8分で打ち切りと書く）
    • 倒れても応援：応援1回で仲間のメーター +20%。速く押しすぎると数えられないので、少し間をあけて押す
    • 一度に戦えるのは4人まで。3時間だけなので、キャンプファイアで人を集めて早めに始める

    MP（マックス粒子）とこの日のボーナス

    • 1戦 800MP（負けたら減らない）。14:00～17:00 は1日に集められる上限が1,600（ふだん800）
    • 0:00～17:00：歩いてもらえるマックス粒子が2倍・必要な距離が1/4 → 午前中に歩いてためる
    • 前の日までに1,500 ためておく → 当日の分（上限1,600）と合わせて約3,100 ＝ 3戦。パックを開ければもっと（1,500 未満のときだけ開けられる）
    • 有料チケット（700円）：マックスバトルの XP が2倍（ゲームウィズ）
    • ディアルガ戦との兼ね合いはない：MP をためる日（11/12・13）とは離れているので、この日は使い切ってよい
