レイドパス（プレミアムバトルパス）狙い

  • 1位 レイドチャンピオンパック 2,380円（通常2,800円・1回だけ・10/19まで）：パス40枚＋リモートレイドパス3枚
  • 　→ 1枚 約46円（リモートを1枚185円で差し引き）／全部まとめて割ると約55円
  • 2位 ハイパーレイドボックス 630円（通常700円・1回だけ）：パス10枚＋まんたんのくすり3＋げんきのかたまり3 → 1枚 約63円
  • 3位 ポケコインを買い、ゲーム内で「3枚 250コイン」：セール時 約64円／通常時 約75円
  • 割高：ウェブストアの「プレミアムバトルパス 3枚 370円」→ 1枚 約123円
  • 無料：ジムのフォトディスクで1日1枚。まずこれを毎日使い切る
  • 目安：★5レイド1回でふしぎなアメ 約2〜3個（体感値・公式の確率は非公開）→ チャンピオンパックなら アメ1個 約20円

マックス粒子（MP）狙い

  • 1位 ポケコイン 15,500枚 11,900円（通常14,000円）→ 1コイン 約0.77円
  • 　→ ゲーム内ショップのマックス粒子パック3個（425コイン・2,400MP）を買う → 250MP 約34円（通常のコイン価格なら 約40円）
  • 2位 ウェブストアのマックス粒子パック6個 1,120円（4,800MP）→ 250MP 約58円
  • 　「マックス粒子パック3個＋リモートレイドパス3枚」も同じ1,120円。リモートを使うならこちら
  • 無料：パワースポット・歩き（2km）で1日800MPまで。パック・リサーチ・コードはこの上限に数えない
  • パックは道具バッグに12個まで持てる → 余ったMPの貯金に使える
  • 比べると：レイドパス1枚 ≒ 250MP の約2倍の値段

ダイきのこ狙い

  • 効果：マックスバトルで与えるダメージが2倍・30分間（通常・スペシャル・ダイマックスわざすべて）。重ねて使うと時間は延びるが、倍率は2倍のまま上がらない
  • ゲーム内ショップ：3個 1,000コイン ／ 1個 400コイン
  • 　→ 3個セットは1個 約257円（セールコイン 0.77円/枚）／約300円（通常コイン 0.90円/枚）。1個買いは約308円／約360円
  • ウェブストア：ダイきのこ3個 ¥1,400（単品の円売りは見当たらず）→ 1個 約467円。コインを貯めずに買えるが割高
  • いちばん安いのはゲーム内の3個1,000コインを、ウェブストアでまとめ買いした割安コインで買う方法（1個 約257〜300円）。ウェブストア直売の¥1,400より安い
  • ダイきのこ入りの有料チケットが出ていればそちらを優先：マックスバトルデイのチケット（約700円＝4.99米ドル相当）＝ダイきのこ1個＋25,000XP＋マックス粒子6,400。XPやMPも欲しい日なら実質おまけでダイきのこが付く
  • 11月のGOパス（ワイルドウィーク）ウェブストア版にも1個：GOパスデラックス（ウェブストア・約2,100円）＝ダイきのこ1個＋マックス粒子パック5個。Web限定の＋10ランク ハイパーボックス（3,500円）はダイきのこ2個
  • 使いどころ：30分の間に何戦も続けて戦うときだけ。1戦だけ・人が多いときは不要。少人数で★5を何戦も回す日（例：マックスバトルデイ）が候補
  • 未確認・買う前にウェブストアで確認：ウェブストアの値段は公式ストアのページで確認（2026-10-22）。ログイン後の画面や最新セールは未確認なので、金額・在庫は買う前にウェブストアで確かめる
