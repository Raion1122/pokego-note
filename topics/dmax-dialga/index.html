    何回で倒せる？（ダイマックス技の回数を逆算）

    • 前提：相手のHP 約75,000（Dittobase の推定値。公式の数字は未発表）、相手の防御の補正 0.85（Pokebase の初期値）。この計算で Lv40・100%のカイリキーが1発345になり、Dittobase の数字と一致。個体値は15/15/15として、CPからレベルを逆算。キノコ（2倍）・応援・相手の強化は入れていない
    • 1発のダメージと、ひとりで倒すのに要る回数（Lv1 → Lv3 にしたとき）
    • ドサイドン（どろかけ → ダイアース）：1発 227 → 331発 ／ Lv3：318 → 236発
    • エースバーン（キョダイ・Lv2）：1発 231 → 325発 ／ Lv3：260 → 289発（相性は等倍だが、キョダイ技は元の威力が高い）
    • カイリキー（CP1698）：1発 184 → 408発 ／ Lv3：257 → 292発
    • ドサイドン（今のうちおとす → ダイロック）：1発 89 → 843発 → 必ずどろかけに替える
    • メタグロス（れんぞくぎり）：1発 83 → 攻撃には使わない。参考：ドリュウズ Lv40・100% は 267（Lv3：374）、カイリキー Lv40・100% は 246（Lv3：345）
    • ダイマックス1回 ＝ 1人3発。4人なら1回で12発
    • 4人全員がドサイドン並み（約230）なら：1回で約2,750 → ダイマックス約28回。全員 Lv3（約320）なら約3,800 → 約20回
    • 近道：①ドサイドンをどろかけに ②ダイアースを Lv2～3 に（1発が約1.3～1.4倍）③カイリキーを強化（CP1698 → 2500前後で1発 約220）④マックスキノコ（2倍）
    • 一度に戦えるのは4人まで（公式ヘルプ）。ポケらくは「最低3人」→ 4人そろえるのが前提（キャンプファイア・現地で集める）
    • 見直し（10/14）：ボスのHPはどのサイトにも未掲載。ポケらくの1発のダメージ（PL40・攻撃15・Lv1でドサイドン345）は上の計算の約1.36倍 → 上の回数は多めに出ている可能性。実際は2～3割少ないかもしれない

    戦い方のコツ

    • 野良では抜けずに受け役を入れ替える：ボスの技（狙い撃ち1つ＋全体攻撃1つ）は挑戦ごとに抽選されるが、途中で抜けると残りの3人が不利になる → 技名を見て、その技に強い手持ちに替える。入り直し（MP は勝ったときだけ減る）は知り合いと組んで、全員で決めたときだけ
    • タンクは通常技だけ連打：スペシャル技よりメーターが早くたまる。0.5秒の通常技（ハピナスのはたく・メタグロスのれんぞくぎり）が向く
    • タンクは2体：1体目で全体攻撃、2体目で単体攻撃を受ける（ドクターポケゴーゴーのおすすめ）
    • エネルギーはスワイプで取る（タップではない）。アイコン1個でメーター +10%
    • 「狙われている」アイコンが出たら左右にスワイプして避ける。全体攻撃は避けられない
    • ダイマックス中は「盾 → 回復 → 攻撃」の順で決める：まずダイウォール（3回まで重ねがけ）、HPが減っていればダイリカバリー、それ以外はダイ攻撃
    • ダイリカバリーは同じ4人グループの「場に出ている」4体だけ回復。控えのポケモンは回復しない
    • 回復量は使ったポケモンの最大HPが基準：Lv1 8%・Lv2 12%・Lv3 16% を4体に同じ量 → ハピナス（HP397）で Lv1 は 31、Lv2 は 47。Lv2 に上げるのが先
    • ★5 は6分40秒で時間切れ。途中からボスの攻撃が強くなる → ダイマックスは出し惜しみしない
    • 倒れても応援：応援1回で仲間のメーター +20%。速く押しすぎると数えられないので、少し間をあけて押す
    • 勝利の報酬：ほしのすな15,000・XP15,000・ふしぎなアメXL1・アメ10・アメXL1・プレミアボール10（現地参加はXP＋2,500・ボール＋2）。色違いの可能性あり

    MP（マックス粒子）の計画

    • 1戦 800MP（ポケらく：負けたら減らない）。持てる上限は1,500、1日に集められるのはふだん800 → 当日は1,600（チケット$11.99なら3,200）
    • 11/14（ディアルガ）：前の晩に1,500持っていれば ＋当日1,600 ＝ 3,100 → 3戦（チケットありなら4,700 → 5戦）
    • 11/15（パルキア）：14日に使い切ると、15日は当日の1,600だけ → 2戦。両日とも戦うなら、14日に700ほど残すと15日も3戦
    • 準備の順番：11/11ごろまではMPをマックス技のレベル上げ（ダイアース・ダイウォール）に使う → 11/12・13は使わずにためて1,500に（1日800なので2日で満タン）
    • リサーチ・コード・粒子パックで入るMPは1日の上限に数えない

    並びと動き方

    • 並び（ドリュウズなし）：ドサイドン（攻撃）／カイリキー（攻撃）／メタグロス（ダイウォール）／ハピナス（回復）
    • メタグロス：りゅうせいぐん・アイアンヘッドをどちらもいまひとつで受けられて、弱点の技がない → ダイウォール役にいちばん向く
    • ハピナス：相性は等倍でもHPが多く、どの技でも受けられる → ダイリカバリーで回復しながら受ける
    • ドサイドン：かみなりはほぼ効かないが、アイアンヘッドは弱点 → かみなりのときだけ前に。それ以外は攻撃に専念
    • サーナイト：りゅうせいぐんはほぼ効かない（フェアリー）が、アイアンヘッドが弱点 → 技名がりゅうせいぐんと分かってから出す
    • 出さない：インテレオン・シャワーズ（かみなりが弱点）、ジジーロン（りゅうせいぐんが弱点）
